# Geolocation Location Demo

[![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)](https://vitejs.dev/)
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=111)](https://developer.mozilla.org/docs/Web/JavaScript)
[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/docs/Web/HTML)

Aplicacion web construida con Vite para practicar el acceso a la ubicacion del navegador y su representacion visual en una interfaz web.

## Funcionalidades

- Solicitud de permisos de geolocalizacion.
- Lectura de coordenadas disponibles en el navegador.
- Interfaz web desarrollada con JavaScript modular.
- Preparacion para integracion con mapas y servicios de ubicacion.

## Tecnologias

- JavaScript
- HTML y CSS
- Vite
- Geolocation API

## Instalacion local

```bash
npm install
npm run dev
```

Abre la URL que indique Vite en la terminal. El navegador puede requerir HTTPS o `localhost` para permitir la geolocalizacion.
